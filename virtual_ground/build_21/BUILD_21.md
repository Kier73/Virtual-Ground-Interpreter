# Build 21 — Controlled Variables, Endogenous Flow, and Ground Revision

## Executive result

Build 21 extends the Virtual Ground from reversible and irreversible symbolic puzzles to a finite, environment-coupled dynamical system. The central experiment distinguishes:

- **structural constraints** — the banks of the system;
- **controlled variables** — commands the observer/controller can select;
- **endogenous variables** — state and flow variables generated by the dynamics;
- **exogenous variables** — environmental forcing not directly controlled by the gate.

The implementation is a deterministic two-reservoir canal fixture. It is deliberately abstract and is not a physical hydraulics simulator.

Four earlier Build 20 checks are included as regressions: Rotor-4 still generates all 648 states; the Support-9 fixture still generates 232 reachable stable states and 774 directed transitions; the layer-count abstraction remains non-congruent.

A bounded navigation compiler is now implemented. It turns an observation into a belief set, synthesizes an observation-contingent policy for an intention, and independently verifies every policy branch. Its certificate is exact for the finite deterministic ground and the supplied observation model.

## Main findings

### 1. Control and environment are different sources of change

A gate command changes the distribution of stored volume. The environment independently introduces inflow, demand and phase progression. Both influence reservoir state, but only the gate command is selected by the controller.

The exact ledger invariant is:

`after_total = before_total + inflow - actual_demand - spill`

All 136 legal transitions satisfy it exactly.

### 2. Partial observations are not automatically Markov state descriptions

Static observation classes were refined by action-labelled partition refinement. In this fixture every partial observer required refinement to all 64 predictive classes. This means none of the selected coarse observations alone is a memoryless, transition-congruent quotient of the full state.

It does **not** mean partial observers cannot navigate. A belief-state controller maintains the set of states consistent with the observation history and chooses actions that work for every remaining possibility.

### 3. Sensor relevance matters more than raw information quantity

From actual state `(1,1,0)`, the task is to reach `a=1,b=2` at any phase. The same hidden world produces these worst-case policy lengths:

| Initial observer | Fixed-width label bits | Initial belief size | Worst-case steps |
|---|---:|---:|---:|
| TOTAL | 3 | 12 | 10 |
| TOTAL_PHASE | 5 | 3 | 8 |
| LEVELS | 4 | 4 | 4 |
| FULL | 6 | 1 | 1 |

These bit counts encode the cardinality of the observation alphabet; they are not measured physical network costs. The LEVELS sensor is more useful than TOTAL_PHASE for this particular intention even though it transmits fewer bits. Sensor value is task-relative.

Belief-search node counts are not monotonic in sensor precision; branching and search topology matter too.

### 4. Resource scarcity changes the selected route

For a fixed start and target, two nondominated plans were found:

| Plan | Time | Energy | Communication |
|---|---:|---:|---:|
| Faster | 7 | 10 | 4 |
| Lower-energy | 11 | 9 | 3 |

The slower plan waits for exogenous inflow and uses fewer gate commands. A tight combined limit of time ≤ 8 and energy ≤ 9 makes the target infeasible under this action set.

### 5. Control can preserve a state property that passive dynamics cannot

For safety predicate `a >= 1 and b >= 1`:

- controlled viability kernel: 35 states;
- HOLD-only autonomous invariant kernel: 0 states.

A state-dependent control policy can keep both stores nonempty indefinitely in the finite deterministic model. Passive evolution cannot.

### 6. Ground version and environment time are different

An ordinary phase advance changes the state but not the ground version. Changing the capacity or the inflow/demand law increments the ground version.

- Capacity expansion 3→4: all 64 old encodings migrate; the new space has 100 states.
- Capacity reduction 3→2: 36 old states map directly; 28 exceed the new capacity. A separate spill/redistribution migration rule would be needed to preserve them.
- Environmental-law revision: all 64 state encodings remain valid, but future transition semantics change.
- Sensor and resource-profile changes alter the compiled observer/controller, not the base transition law.

A resource budget can still restrict the *effective operational ground* by making some otherwise legal actions unavailable or infeasible.

## Limitations

- Finite, discrete, deterministic model only.
- Environmental forcing is a known four-phase cycle, not stochastic or chaotic.
- No continuous fluid dynamics, pressure, friction, delay or sensor noise.
- Sensor observations are exact; uncertainty comes from hidden state, not measurement error.
- Resource costs are synthetic units for comparing paths, not measured joules or network traffic.
- Strong bisimulation refinement concerns this specific action-labelled transition system.
- Constant-time navigation is not established. Belief search and Pareto planning have explicit state/label costs.
