# Sources and provenance

## Primary conceptual source

`Questions_On_the_Virtual_Ground_SOURCE.md` is the user-provided document attached to the Build 20 request. It is copied unchanged into the package. The terminology and conceptual premises in the formalization are drawn from that document, particularly its sections on Virtual Ground, Consensus, Compression, Navigation, Time, Intention, Memory and Observation.

## Prior project context

Build 20 extends the mathematical and software progression recorded in Builds 01–19, especially:

- Build 15: local-clock event graphs and observer-specific time coordinates.
- Build 16–17: symmetry-adapted harmonic representations and invariant comparisons.
- Build 18: SU(2), Hopf quotient and path signatures.
- Build 19: endpoint/path/observer decomposition and kernel geometry.

## Provenance of results

All Build 20 numerical results are generated by `virtual_ground.py` and `experiment.py` from the included finite synthetic rotor-puzzle fixture. They are not measurements from a Rubik's Cube, Jenga, TAPS, or any external physical system.

## Mathematical scope

The finite construction uses elementary permutation groups, modular orientation coordinates, semidirect-product composition, graph search, and observer-induced equivalence classes. The package makes no claim that its toy algebra captures every property of the user's broader Virtual Layer architecture.

## Build 20 inference

`VIRTUAL_GROUND_COMPILER.md` is a proposed architecture derived from the user's stated roles for ground, observer, intention, memory and navigation. It is not asserted as wording from the source note.
