# Partial and Irreversible Virtual Ground — Jenga-like Support Logic

## Why a second fixture is necessary

The rotor puzzle is a finite group: every primitive operation is invertible, and all state transitions are generated by a reversible operation algebra. That is useful for composition, but it does not cover games and systems whose legal actions depend on the current state and cannot be undone.

The supplied user's Jenga analogy motivates a second fixture with partial, irreversible transitions.

## Abstract support model

This is a small symbolic support graph, not a physical Jenga or structural-mechanics simulator.

There are three layers of three blocks:

- base: blocks 0, 1, 2;
- middle: blocks 3, 4, 5;
- top: blocks 6, 7, 8.

Each middle block has two possible supports in the base layer. Each top block has two possible supports in the middle layer. A state is a 9-bit occupancy mask. A state is stable when every remaining elevated block has at least one remaining support in the layer below.

Removing block \(i\) is legal when:

1. block \(i\) is present;
2. the resulting occupancy mask still satisfies the declared stability predicate.

Removal is irreversible. The transition graph is directed and acyclic because every action decreases the number of present blocks by one.

## Results

| Measure | Original support ground | Revised support ground |
|---|---:|---:|
| Ground version | 1 | 2 |
| Reachable stable states | 232 | 200 |
| Directed removal edges | 774 | 646 |
| Maximum removal depth | 9 | 9 |

The revision changes the support rule for top block 6 from two possible supports (3 or 4) to support only from block 3. The reachable state region shrinks from 232 to 200.

This is a ground shift: it changes the logic that decides which states and transitions are valid, rather than changing coordinates over an unchanged system.

## Observer limitation

A coarse observer that records only the count of blocks remaining in each layer is not transition-congruent. Two states can have identical level counts but different identities of the remaining supports, and therefore different legal removal actions.

A representation that preserves only the three layer counts cannot safely navigate this ground with labelled `REMOVE_i` actions. It must retain support identity or another sufficient statistic.

This is a direct demonstration that a compact view can be inadequate even when its aggregate measurements look identical.

## What this fixture supports

- Virtual Grounds may define partial transition maps.
- Legal actions can depend on the exact current state.
- Irreversible actions generate directed rather than group-like state graphs.
- A ground revision can change the reachable region.
- Observer equivalence must be checked for transition congruence, not assumed from a visually convenient summary.

## What it does not support

- It does not predict the physical stability of a real Jenga tower.
- It does not model gravity, friction, deformation, load transfer, uncertainty or human dexterity.
- It does not establish a universal formalization for all irreversible systems.
