# Competing Explanations — Build 27

## Diagnostic principles

1. A single contradiction is not a new ground.
2. Repeated support for an unchanged rule is evidence-strengthening, not structural revision.
3. A longer predictive history can resolve an apparent state collision without asserting a new physical state.
4. A hidden deterministic variable and stochastic output may be indistinguishable under the current probe family.
5. A sensor offset cannot be called calibration drift unless an independent reference remains stable.
6. A regime-change proposal needs persistent conflicts across distinct context-operation pairs and corroboration from more than one sensor.
7. New operation candidates need recurrent event signatures and consistent effects; one-off tokens remain unclassified.
8. No diagnostic score is a probability. The next experiment is often more valuable than a forced label.

## Explanation score table

Scores are ordinal ranks produced by explicit evidence rules. They must not be read as confidence percentages or Bayesian posterior values.

## Important ambiguity pairs

- New observed state vs sensor remapping.
- Hidden predictive variable vs memory horizon longer than tested.
- Deterministic hidden context vs stochastic transition.
- Ground regime change vs sensor-system change.
- New operation vs a recurring event signature that is merely correlated with a system response.

## Required discipline

Every candidate explanation should carry:

- observed supporting evidence;
- contradictory or missing evidence;
- a discriminating next test;
- a declaration of whether it authorizes ground revision (Build 27 never automatically authorizes revision).
