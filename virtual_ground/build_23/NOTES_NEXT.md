# Next Research Steps

## Build 24 candidates

1. Latent context discovery: infer an unobserved phase/state variable from repeated residual patterns in state/action traces.
2. Noisy observations: replace exact elimination with likelihoods, posterior calibration and robust active probing.
3. Asymmetric operations: infer separate directional action laws and state-dependent action legality.
4. Open expression synthesis: add guarded piecewise expressions and integer relations, retaining explicit search budgets.
5. Ground equivalence: determine when two different induced programs are behaviorally equivalent over all reachable states and tasks.
6. Productive ground evaluation: compare task-relevant transition coverage, compute cost, regeneration cost, storage and adaptation cost against materialized tables.

The next decisive step is likely latent context discovery with held-out interventions, because Build 23 currently receives `phase` as an observed state field.
