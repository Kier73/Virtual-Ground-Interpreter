# Build Lineage

- Builds 01–10 developed observer-dependent response geometry, paths, holonomy, codonic composition, S3/Hopf observation, active probing and synthetic cross-domain cautions.
- Builds 11–13 established empirical-data acquisition discipline and paired throat/acoustic processing pipelines; no TAPS measurements were claimed where audio could not be retrieved.
- Build 14 introduced separate normalized temporal-interval shape and absolute temporal rate.
- Build 15 introduced local-clock event graphs and cross-stream correspondences.
- Builds 16–17 compared harmonic representations and symmetry-specific invariants.
- Builds 18–19 formalized the relational invariant atlas, SU(2)/Hopf observer quotients, path signatures, endpoint/path distinction and observer kernels.
- Build 20 formalized finite reversible and irreversible Virtual Grounds and compositional navigation.
- Build 21 separated controlled, endogenous, exogenous and structural variables, plus belief-state navigation and ground versioning.
- Build 22 introduced active discovery over a predefined candidate catalogue and showed why independent holdout validation is necessary.
- Build 23 induces a finite generative ground program from transition observations without giving the learner a candidate ground catalogue.

Build 23 does not replace the prior representation work. It adds an upstream generator whose trajectories, transformations and observations can later be mapped into those representations.
