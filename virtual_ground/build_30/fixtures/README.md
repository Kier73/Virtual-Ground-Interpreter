# Build 30 Signal Fixtures

All files here are synthetic, generated by `run_build30.py`.

- `signal_program_control_fsk.wav`: mono FSK instruction-control stream, including a 37-sample leading offset, preamble, opcodes, complement checks and small additive noise.
- `instruction_0_operands_iq.wav`: eight PCM channels representing I/Q signal and pilot pairs for the first instruction's two operands: A-I, A-Q, A-pilot-I, A-pilot-Q, B-I, B-Q, B-pilot-I, B-pilot-Q.
- `instruction_0_output_iq.wav`: two PCM channels containing the resulting output carrier I and Q for the first instruction.

The I/Q WAVs are numerical analysis fixtures, not intended as ordinary stereo audio playback. Quantization to 16-bit PCM is for inspectability; the results JSON records the higher-precision in-memory computation.
