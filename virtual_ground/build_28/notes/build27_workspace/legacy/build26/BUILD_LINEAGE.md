# Build Lineage — Builds 20–26

- **Build 20:** Virtual Ground formalization; reversible finite transformation logic and partial irreversible support logic; intention-relative navigation.
- **Build 21:** controlled, endogenous, exogenous and structural variables; belief navigation; resources, viability and version migration.
- **Build 22:** active identification inside a supplied finite candidate family; out-of-family validation and revision proposals.
- **Build 23:** symbolic rule induction from transition records; counterexample-driven grammar expansion; executable ground serialization.
- **Build 24:** resettable latent predictive-context discovery via an L*-style observation table; observer quotients; delayed counterexample refinement; modular phase or finite automaton compilation.
- **Build 25:** non-resettable online tracking of unknown predictive context using an existing Build 24 machine; asynchronous partial outputs; local-clock discipline; contradiction quarantine; bounded memory.
- **Build 26:** incremental construction of a partial predictive ground from a continuing stream. It explicitly retains unknown transitions, refines history horizon after collisions, maintains evidence/version lineage, and compiles only the observed partial machine.

## The architectural progression

\[
\text{Observe}
\rightarrow\text{infer predictive context}
\rightarrow\text{induce partial transitions}
\rightarrow\text{compile a partial ground}
\rightarrow\text{validate and revise}
\]

The sequence is not yet an unrestricted self-learning interpreter. It assumes a known finite action alphabet and selected integer-valued observation channels. The learned contexts are observer-relative predictive history classes and may over-split when evidence is sparse.
