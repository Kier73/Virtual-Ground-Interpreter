# Sources and Provenance

## Project-internal sources

- `notes/build24_recovery/`: exact Build 24 source, tests, reports, specifications and original ZIP archive, recovered from Build 25's preserved legacy folder.
- `legacy/build24/`: executable Build 24 copy used for Build 26 hidden-test fixtures and regression.
- `legacy/build25/`: Build 25 online tracker and regression suite.
- `Questions_On_the_Virtual_Ground_SOURCE.md`: user's Virtual Ground notes embedded in the prior build series and retained through the Build 24 source bundle.

## External methodological lineage

Build 24 documented its observation-table learner as L*-style active Mealy-machine learning. Build 26 does not claim to implement a complete formal active automata-learning algorithm for non-resettable streams; it uses bounded predictive suffix contexts, partial-transition consistency, and collision-driven horizon refinement.

## Provenance boundary

All Build 26 measurements are generated by deterministic finite synthetic test fixtures. Build 24's hidden-context generators are used only as test oracles. The Build 26 learner API receives neither hidden modes nor reset queries. No TAPS or physical sensor data was processed.
