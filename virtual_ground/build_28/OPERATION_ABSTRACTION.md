# Operation Abstraction and Partial Ground

A recurring token motif is initially an **event motif**, not automatically an operation. Build 28 separates:

1. recurrence of an ordered event pattern;
2. an inferred state effect from checkpoint equations;
3. causal interpretation, which requires intervention or ablation.

An effect is compiled only when the checkpoint count matrix identifies a unique exact integer vector. A zero-effect motif remains in the catalog but is not promoted to a state-changing operation. Unknown motifs and unresolved effects remain unknown.

The partial ground fingerprint covers the compiled structure, not support counters or incidental trace IDs. The JSON round trip is validated before the interpreter applies it.
