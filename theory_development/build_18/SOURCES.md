# Sources and mathematical grounding

1. Taujanskas, *Wave Map Null Form Estimates via Peter–Weyl Theory* (Cambridge repository). Appendix A identifies S3 with SU(2), states normalized Haar measure, the irreducible representation dimensions, Laplacian eigenvalues, Schur orthogonality, Peter–Weyl expansion and Plancherel formula.
   - https://api.repository.cam.ac.uk/server/api/core/bitstreams/f2a24277-092c-41c0-bafb-c6bf586c843b/content
   - Referenced in this conversation as `turn477106view0`, especially `turn341292view0` and `turn341292view1`.

2. Hambly & Lyons, *Uniqueness for the Signature of a Path of Bounded Variation and the Reduced Path Group* (2005/2006). Establishes that equal signatures characterize bounded-variation paths up to tree-like equivalence, with path concatenation and reversal forming the reduced path group.
   - https://arxiv.org/abs/math/0507536
   - Referenced in this conversation as `turn477106view1` and `turn782357view1`.

3. Rupe, Vesselinov & Crutchfield, *Nonequilibrium Statistical Mechanics and Optimal Prediction of Partially-Observed Complex Systems* (2022). Defines Koopman action on observables and discusses projection/memory for partially observed systems.
   - https://csc.ucdavis.edu/~cmg/papers/ktpe.pdf
   - Referenced in this conversation as `turn477106view2`, especially `turn782357view2` and `turn782357view3`.

4. Murphy, *A Course in Harmonic Analysis* (2019). Open course material for Fourier analysis, LCA groups, Plancherel, compact groups and wavelet transforms.
   - https://scholarsmine.mst.edu/oer-course-materials/2/
   - Referenced in this conversation as `turn477106view3`.

The code in this package is original implementation and synthetic numerical verification. The sources ground the mathematical theorems; they do not validate an empirical Virtual Layer or sensor system.
