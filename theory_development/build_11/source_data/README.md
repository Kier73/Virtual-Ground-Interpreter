# Source data and attribution

`measurement_01_excerpt.csv` is a selected excerpt from measurement 01 in:

Justyna Witulska, *Vibration measurements with observer-declared variance change points*, version 1.0.0 (2026-09-19), Creative Commons Attribution 4.0 International (CC BY 4.0).

Repository: https://github.com/witulska/vibration-changepoint-dataset
Canonical CSV: https://raw.githubusercontent.com/witulska/vibration-changepoint-dataset/main/data/processed/measurement_01.csv

The original source-line numbers are retained in the `source_line` column. The eight selected windows and their inclusive source-line ranges are documented in `source_manifest.json`. The excerpt is adapted by selecting disjoint source ranges and adding `window_id` and `source_line` fields. Values are otherwise retained as presented in the source CSV. No interpolation, resampling, smoothing, or value modification is performed in this excerpt file.
