# Build 03 — Next questions

1. Replace the hand-selected shear loop with a graph generated from algebraic
   rewrite/equivalence rules.
2. Define observer base nodes explicitly as equivalence classes, not merely
   rounded scalar outputs.
3. Define a fibre and a gauge action, then check the connection compatibility
   conditions required for a proper discrete principal connection.
4. Separate semantic equivalence from observed equivalence. An observer may
   identify two outputs while the underlying algebraic states remain distinct.
5. Test loops built from more than two primitive operations and from multiple
   codon registry profiles.
6. Compare the same graph under alternative coordinate embeddings, including
   quaternion/S3 representations, without assuming that bitwise SHA complements
   are geometric antipodes.
7. Add noise to observations and compare raw, filtered and innovation channels.
8. Compare holonomy conjugacy classes, graph cycle bases, and spectral properties
   across observers.

Most important falsification test: construct different codonic paths with the
same observer-visible base loop. If the resulting holonomy is always identity
once all algebraic equalities and the full hidden state are correctly retained,
then nontrivial results in an earlier version may have been produced by a lossy
quotient, an incorrect transport rule, or an implementation error.
