# Build 19 experiment protocol

1. Construct deterministic quaternion trajectories on S3.
2. Generate three observers: full S3 lift, SO(3) rotation quotient, and Hopf S2 base quotient.
3. Build endpoint feature maps from finite SU(2) irreducible sectors.
4. Build path features from ambient truncated path signatures.
5. Form PSD Gram kernels for endpoint, path and their direct-sum combination.
6. Compare reference-path distances against alternate-route, fibre-shifted, reparameterized, tree-like and antipodal controls.
7. Validate kernel PSD, induced-distance identity, common-action invariance, time-augmentation sensitivity and small-noise response.
8. Run inherited Build 18 tests and new Build 19 tests.

All trajectory generation and transformations are deterministic. The experiment does not load external audio, speech, room-response, or motion-sensor data.
