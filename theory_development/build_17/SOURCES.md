# Sources and provenance

## Code and data provenance

- Build 14–16 implementations and tests are included as inherited project code in this package.
- Build 17 temporal signals and event times are deterministic synthetic fixtures generated by `temporal_representations.py`.
- No TAPS recordings, human participant data, room impulse responses or physical sensor files were processed in Build 17.
- The TAPS retrieval manifest is retained from Build 13/14 for continuity only; it is not evidence of empirical analysis in this build.

## Mathematical conventions used

- Finite DFT: unitary normalization `1/sqrt(N)` and negative-exponent forward convention.
- STFT: circular Hann-window frames, with explicit frame size and hop.
- Mellin: sampled uniformly in `u=log(t)`, using the `L²(R₊, dt/t)` measure. This is Fourier analysis in log coordinates.
- Graph Fourier: combinatorial Laplacian `L=D-A`, with real symmetric eigendecomposition.
- Eigenspace comparisons: group repeated eigenvalues and compare projected energy, rather than comparing arbitrary eigenvector columns.

The package documents the exact finite conventions used; its results should not be generalized beyond those conventions without further tests.
