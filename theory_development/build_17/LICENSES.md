# Licensing and data scope

## Code

The inherited project license is in `LICENSE` (MIT). Review it before reuse or redistribution.

## Research source material

`SOURCES.md` links to external papers and lecture notes. This package does not include their full texts. Their respective licenses and citation requirements apply independently.

## Dataset scope

No participant audio, transcripts, demographics, speaker identifiers or derived participant data are included. Build 16's benchmarks are synthetic generated signals only. The presence of inherited Build 14 code does not imply that TAPS data were downloaded, processed or redistributed.
